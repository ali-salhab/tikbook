TikBook 3D Gift Assets
======================

These are sample Lottie JSON files you can use to test the 3D Gift functionality.
Upload these files via the Admin Panel -> Gifts section.

Files:
1. heart.json - A pulsing red circle (Heart simulation)
2. rose.json - A spinning pink square (Rose simulation)
3. rocket.json - A blue shape flying upwards (Rocket simulation)

Note: For real production quality 3D gifts, you should download high-quality Lottie JSON files from sites like Lottiefiles.com.
